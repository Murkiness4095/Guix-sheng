## Guix 与 NixOS 间切换后手写笔重复提示

2026-11-25 实测，从 Guix 切回 NixOS 后，Xiaomi Focus Pen 多次弹出连接提示。NixOS 仍显示已配对和已信任，但 BlueZ 多次读取 HID 属性失败，笔未保持连接。两套系统使用同一蓝牙控制器地址，分别保存到本机的配对密钥实测不同。

保留 NixOS 原记录并同步 Guix 中已验证可用的这支笔的配对记录后，NixOS 恢复连接并枚举出笔的 HID 输入设备。当前没有自动同步机制。在任一系统里删除笔并重新配对后，另一边的记录可能再次失效。此记录适用于这次 Guix / NixOS 实机组合，Android / NixOS 未复现同一现象。
